# 系统日志追溯整改清单

- [x] 写接口统一记录请求 ID、路由模板、HTTP 状态、耗时和客户端信息
- [x] 记录脱敏后的路径参数、查询参数和请求体
- [x] 支持一个请求关联多个业务对象 ID
- [x] 保存操作人用户名快照，避免用户删除后无法识别

- [x] 扩展日志查询条件
- [x] 为关键接口增加业务动作元数据

## 第二阶段：业务变更快照

- [x] 员工报工记录 `batch_step_records` 变更前后快照

- [x] 工单下达、关闭、取消及计划数量变更前后快照
- [x] 物料分配与清除记录分配前后数量、物料批次和生产批次

- [x] 增加日志保留、归档和清理策略
- [x] 增加业务单号、请求 ID、目标对象和时间范围组合检索
- [x] 日志详情页展示请求参数、多个目标 ID、状态码和字段差异
- [x] 为脱敏、目标识别和失败日志增加自动化测试
