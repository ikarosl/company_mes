## 二、迁移脚本说明

### 1. 数据库结构脚本

```text
docs/20260629_apply_unified_inventory.sql
```

作用：

- 创建统一库存对象表：`item_type`、`item_info`
- 创建统一 BOM 表：`product_bom`
- 创建统一库存批次表：`item_batch`
- 创建统一库存流水表：`inventory_transaction`
- 创建入库、出库、退料、报废、盘点相关表
- 创建库存和生产物料汇总视图
- 删除旧方案二中已被推翻的 `material_batch`、`material_demand`、`material_allocation` 等表

注意：

- 该脚本会 `DROP` 部分旧仓储表和旧视图。
- 该脚本不会迁移旧测试数据。
- 执行前必须备份数据库。

### 2. 权限迁移脚本

```text
docs/20260629_unified_inventory_permissions.sql
```

作用：

- 新增统一库存对象、入库、出库、退料、报废、盘点权限点
- 停用已推翻的旧仓储出入库权限点
- 给已有仓储根权限角色补齐新仓储权限

## 六、常见问题

### 1. 执行 SQL 后中文变成问号

原因通常是使用 PowerShell 管道执行 SQL 文件。

处理方式：

- 恢复备份
- 使用 `mysql --default-character-set=utf8mb4`
- 进入 MySQL 后用 `SOURCE` 重新执行脚本

### 2. 外键创建失败

先检查被引用表是否存在：

```sql
SHOW TABLES LIKE 'work_orders';
SHOW TABLES LIKE 'production_batches';
SHOW TABLES LIKE 'users';
```

再检查字段类型：

```sql
SHOW CREATE TABLE work_orders;
SHOW CREATE TABLE production_batches;
SHOW CREATE TABLE users;
```

新脚本默认引用 `BIGINT UNSIGNED` 主键。如果现有表字段类型不一致，需要先调整脚本或基础表字段，不能强行绕过外键。

### 3. 权限迁移后菜单不显示

检查三个位置：

```text
packages/constants/src/permissions.ts
packages/api-contract/src/routes.ts
apps/admin-web/src/views/AdminLayout.vue
```

再检查当前登录用户角色是否拥有新权限：

```sql
SELECT r.code AS role_code, p.code AS permission_code
FROM users u
JOIN user_roles ur ON ur.user_id = u.id
JOIN roles r ON r.id = ur.role_id
JOIN role_permissions rp ON rp.role_id = r.id
JOIN permissions p ON p.id = rp.permission_id
WHERE u.username = 'admin'
  AND p.code LIKE 'warehouse:%'
ORDER BY p.code;
```
