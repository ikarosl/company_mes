# 生产工艺流程追溯系统一期需求说明书 V2.1 页面级代码生成版

> 用途：按 routes.ts 实际路由拆分页面需求，供 AI 逐页生成 Vue 前端页面、服务层接口、Mock 数据和测试用例。

## 一、统一代码生成要求

- 使用 Vue 3 + TypeScript + Element Plus。
- 路由 path、name、permission 以 routes.ts 为准。
- 页面统一采用：页面标题区 + 查询区 + 表格区 + 分页 + 弹窗表单/详情弹窗。
- 接口封装到 service 文件，不要散落在组件中。
- 接口未完成时先使用 mock 数据，但字段名贴近后端 DTO。
- 状态字段集中维护枚举映射，不要在页面中到处写死中文。
- 新增、编辑、确认、状态动作必须有 loading、防重复提交、错误提示。
- 不要一次生成整个系统，应按页面小节逐页生成。

## 三、页面级详细需求

### 1. 登录页

- 所属模块：登录与首页
- 路由路径：`/login`
- 路由名称：`login`
- 组件：`LoginPage.vue`
- 权限：`guestOnly`
- 页面状态：已有组件
- 页面类型：表单页
- 页面目标：提供账号密码登录入口，登录成功后写入访问令牌并跳转首页；已登录用户访问时应跳转首页。
- 主要数据表/对象：`users、refresh_tokens；前端使用 auth store 保存 token、用户信息和权限码。`

#### 接口建议
- `POST /auth/login`
- `GET /auth/me`
- `POST /auth/logout`

#### 页面布局
- 居中登录卡片：系统名称、账号输入、密码输入、登录按钮。
- 登录失败使用消息提示，不跳转；登录成功后进入 /。
- 按钮 loading 防重复提交。

#### 查询、列表、操作、表单
- 查询条件：无。
- 列表/展示字段：无列表。
- 页面操作：登录；回车提交；错误提示；自动跳转
- 弹窗/表单字段：username：必填；password：必填；rememberMe：可选，一期可不实现

#### 业务规则与校验
- 账号或密码为空时前端拦截。
- 接口返回无权限或停用用户时提示“账号不可用或无权限”。
- 登录后根据 permissions 控制菜单和按钮。

#### AI 代码生成备注
> 生成 LoginPage.vue、auth store、路由守卫。不要把权限写死在页面里，权限来自后端 /auth/me 或本地模拟权限数据。

### 2. 首页

- 所属模块：登录与首页
- 路由路径：`/`
- 路由名称：`dashboard`
- 组件：`DashboardPage.vue`
- 权限：`PERMISSIONS.dashboard.page`
- 页面状态：已有组件
- 页面类型：概览页
- 页面目标：展示系统当前生产、物料、质量和待办概览，是进入各业务页面的导航入口。
- 主要数据表/对象：`work_orders、production_batches、batch_step_records、batch_material_usages、inspection_records、rework_records。`

#### 接口建议
- `GET /dashboard/summary`
- `GET /dashboard/todos`
- `GET /dashboard/recent-activities`

#### 页面布局
- 顶部显示四个统计卡片：待处理工单、生产中批次、待检验数量、返工中数量。
- 中部显示待办列表和快捷入口。
- 底部显示最近操作或最近批次动态。

#### 查询、列表、操作、表单
- 查询条件：可选时间范围，一期可默认近 7 天。
- 列表/展示字段：待办列表：类型、对象编号、标题、状态、负责人、更新时间、操作。
- 页面操作：跳转工单管理；跳转生产任务；跳转检验记录；跳转返工记录；查看待办详情
- 弹窗/表单字段：无新增表单。

#### 业务规则与校验
- 首页只做汇总展示，不在首页直接修改业务数据。
- 统计口径来自后端聚合接口，不建议前端多次联表。

#### AI 代码生成备注
> 生成 DashboardPage.vue，使用 Element Plus 卡片、表格和空状态；接口未完成时使用 mockDashboardSummary。

### 3. 用户管理

- 所属模块：系统管理
- 路由路径：`/system/users`
- 路由名称：`system-users`
- 组件：`SystemUsersPage.vue`
- 权限：`PERMISSIONS.system.users.page`
- 页面状态：已有组件

- 页面头部：标题、说明、新增按钮。
- 查询区：账号/姓名、部门、角色、状态。

- 查询条件：账号/姓名关键词、部门、角色、状态。
- 列表/展示字段：账号、姓名、部门、岗位、角色、手机号、状态、创建时间、最后登录时间、操作。

- 弹窗/表单字段：username：必填、唯一；real_name：必填；department_id：下拉选择；post_name：可选；phone：可选；status：active/disabled；role_ids：角色多选，保存到 user_roles

#### 业务规则与校验
- 用户名唯一。
- 停用用户不可登录。
- 角色不能保存在 users.role_ids，应通过 user_roles 保存。
- 新增、停用、重置密码、分配角色需要写 logs。
