生产报工
按「生产批次号」分块展示，与派工管理结构一致。
每道工序独立报工，分为「开工」和「完工」两步。
开工时记录开始时间，完工时填报生产数据。
管理端可直接填报所有工序的报工数据。

    ┌─────────────────────────────────────────────────────────────────────────────┐
    │ 生产批次号：SCPC-20260609-002         任务状态：🟢 生产中                  │
    │ 工单：ORD-20260609-001   产品：宽带微带环形器   数量：60 pcs               │
    │                                                                             │
    │ 工序 │ 操作员 │ 开工时间         │ 完工时间  │ 合格/总  │ 报工状态 │ 操作 │
    │──────┼───────┼─────────────────┼──────────┼─────────┼─────────┼────────│
    │ 装配 │ 张三  │ 06/10 08:00     │ 06/10 10:30 │ 38/40 │ 已确认  │ [查看] │
    │ 调试 │ 李四  │ 06/10 11:00     │ —        │ —/—     │ 已开工  │ [完工] │
    │ 检验 │ 王五  │ —               │ —        │ —/—     │ 未开工  │ [开工] │
    │ 包装 │ 赵六  │ —               │ —        │ —/—     │ 未开工  │ [开工] │
    │                                                                             │
    │                           [开工并报工] [批量报工]                            │
    └─────────────────────────────────────────────────────────────────────────────┘

    操作说明：
    ─────────────────────────────────────────────────────────────────────────────
    [开工]         → 记录该工序开始时间，操作员从派工数据自动带入
    [完工]         → 弹出报工表单，填写以下数据：
                      完工时间（默认当前时间，可修改）
                      完成数量       本次生产完成的总数量
                      合格数量       = 完成数量 - 不合格数量
                      不合格数量     不合格的数量
                      不合格原因     下拉选择：尺寸超差 / 外观不良 / 性能不达标 / 其他
                      异常说明       文本描述异常情况
                      上传文件       检测记录、异常照片等
                      备注           其他说明
    [查看]         → 查看已确认的报工记录详情
    [开工并报工]   → 一步完成开工和完工报工（适用于一道工序一次完成的情况）

    字段补充说明：
    ─────────────────────────────────────────────────────────────────────────────
    1. 开工时间：记录工序实际开始生产的时间点
    2. 完工时间：记录工序实际完成的时间点
    3. 合格数量：完工报工时填写，合格品数量
    4. 完成数量（总）：合格数量 + 不合格数量
    5. 报工状态：未开工 → 已开工 → 已报工(待确认) → 已确认
    6. 不合格原因：生产中出现质量问题时记录，便于后续质量追溯
    7. 文件上传：支持上传生产记录表、检验图片等，关联到该工序的报工记录
